VitalX POD'S

Module mobile de simulation multiparamétrique basé sur iPhone, conçu pour le contrôle à distance des constantes (PNI, SpO₂, SpCO, glycémie, cétonémie, lactatémie, hémoglobine) avec interface professionnelle inspirée du moniteur VitalX.

📋

Description générale

VitalX POD'S est un module compact de simulation paramédicale pensé pour utiliser un iPhone comme moniteur patient dans le boîtier POD'S, pendant que le formateur pilote les constantes et les scénarios depuis un iPad dédié.


Le boîtier VitalX POD'S accueille l’iPhone-moniteur et les accessoires (brassard tension, câble SpO₂/SpCO, patch DSA) pour reproduire un environnement de travail réaliste : PNI, SpO₂, SpCO et BIO (glycémie, cétones, lactates, hémoglobine) sont directement affichés côté iPhone, tandis que le formateur garde la main sur l’évolution du cas depuis l’iPad.


La logique d'affichage et de contrôle reprend celle de ton application : bascule VITALS / BIO, bouton PNI dédié avec son de mesure, affichage conditionnel des constantes uniquement lorsque les capteurs sont connectés ou la mesure PNI terminée, et courbe SpO₂ (normale ou bad SpO₂) selon les paramètres envoyés. Le POD'S intègre aussi un mode DSA simplifié sur l’iPhone avec métronome de RCP pour les séances courtes et les ateliers.
