Ce que c'est

Un moniteur compact,
piloté à distance.

Le boîtier VitalX POD'S accueille l'iPhone-moniteur et ses accessoires — brassard de tension, câble SpO₂/SpCO, patch DSA — pour reproduire un poste de travail réaliste dans un format qui tient dans une pochette. Le formateur pilote les constantes et l'évolution du cas depuis un iPad, un iPhone ou le mode formateur web.

L'affichage reprend la logique du moniteur VitalX : bascule VITALS / BIO, bouton PNI avec son de mesure, constantes affichées uniquement quand les capteurs sont connectés ou la mesure terminée, courbe SpO₂ normale ou dégradée. Le POD'S intègre aussi un mode DSA simplifié avec métronome de RCP.

Synchronisation en temps réel par Wi-Fi ou partage de connexion, avec un code de session : plusieurs POD'S peuvent suivre le même scénario.
